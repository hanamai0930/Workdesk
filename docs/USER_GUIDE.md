# Workdesk 使用指南

适用于 **Workdesk · Windows 11 x64**。

## 先认识 Workdesk

**Workdesk 是一个把 AI 聊天、项目工作、模型协作和资料管理放在一起的 Windows 工作台。** 你可以用它讨论问题，也可以连接模型的官方工作端，让模型在指定项目中读写文件、运行工具、完成任务，并把过程、成果和验收记录留在同一个地方。

Workdesk 使用你自己的模型账号或 API Key。当前提供 Codex、DeepSeek、Qwen 的工作连接，以及 API 聊天和官方网页聊天入口。

### 一套工作台，三种工作方式

|方式|它帮你做什么|从哪里开始|
|---|---|---|
|**Chat**|问答、讨论、阅读附件、整理思路|发一个问题，或附上一份需要阅读的资料|
|**独立 Work**|由一个官方工作端持续处理项目文件与工具任务|选择项目，写清目标，点击发送箭头|
|**合作 Work**|让多个模型按固定流程、负责人带队或主持人—专家方式分工|填写目标，核对合作安排，再开始执行|

### 从想法到成果，都能接着做

- **围绕项目工作**：将对话、任务、文件位置和成果放到所属项目下，方便后续接着处理。
- **边聊边整理**：在右栏写页面、整理演示文稿、预览文件，收录到资料空间或导出。
- **看得见执行过程**：查看当前状态、审批、回合、用量和已保存的成果版本。
- **由你决定是否完成**：模型完成回合后，打开实际文件、保存成果，再接受或退回版本。

第一次使用，从[启动与快速上手](#chapter-1)开始。已经连接账号，可以直接阅读 [Chat](#chapter-4)、[独立 Work](#chapter-5)或[合作 Work](#chapter-6)。

## 一、启动与快速上手

### 1. 启动 Workdesk

从源码启动请按[开发说明](DEVELOPMENT.md)构建前端并启动本地工作台。首次打开时选择账号连接方式，再点击 **进入工作区**。

### 2. 十分钟完成第一次使用

**先试一次聊天：**

1. 在连接页选择 **API Key**，保存自己的 DeepSeek 或 Qwen Key。
2. 进入工作区，切到 **Chat → API 连接**，选厂商和型号。
3. 输入“请帮我列一个本周工作安排模板”，点击输入框右下角的发送箭头。
4. 等待回复，试着复制一段文字，或在原对话继续提问。

**再试一个文件任务：**

1. 准备一个专门练习用的项目文件夹。
2. 切到 **Work → 独立**，选择该项目、工作端和型号。
3. 输入下面的目标，点击输入框右下角的发送箭头：

> 在这个项目中创建一份说明文档，写出项目目标、下一步和待确认事项。完成后告诉我文件位置。

4. 遇到审批时，阅读请求后选择批准或拒绝。
5. 回合结束后打开文档，再到任务详情的 **成果与验收** 保存成果、记录验收决定。

### 3. 关闭与退出

关闭窗口后，后台服务可以继续运行。需要完全退出时，先处理在途工作，再重启 Windows。个人资料保存在开发说明所列的资料位置。

## 二、连接自己的账号

### 1. 选对连接方式

|你要做什么|选择什么|在哪里连接|
|---|---|---|
|通过 API 聊天|DeepSeek 或 Qwen API Key|连接页 **API Key**|
|在 Workdesk 内使用官网聊天|ChatGPT、DeepSeek 或 Qwen 官网账号|连接页 **Chat 账号**|
|让模型操作项目文件与工具|Codex、DeepSeek Harness 或 Qwen Code 工作连接|连接页 **Work 账号**，或对应 API Key|

官网订阅、API 余额和工作端授权分别管理。连接后可以在 **设置 → 账号与模型** 查看工作连接，在 **设置 → Chat 接入** 选择聊天默认项。

### 2. 连接 API Key

1. 在连接页点击 **API Key**，选择 DeepSeek 或 Qwen。
2. 输入该提供方开放平台的 Key，点击 **验证并保存**。
3. 按提示检查连接，回到工作区选择厂商与型号。
4. 需要设为默认时，打开 **设置 → Chat 接入** 保存默认渠道、厂商和型号。

Qwen 普通 API Chat 使用通用按量 API Key。DeepSeek、Qwen 的 API 工作路线也使用你保存的对应 Key。

**注意：** API 调用和联网搜索按提供方的计费规则结算，账单以官方记录为准。Key 通过连接页保存，保存位置与保护方式见[数据与备份](#chapter-12)。

### 3. 连接官网 Chat

1. 点击 **Chat 账号**，选择厂商。
2. 在打开的官网页面完成登录。
3. 回到 Chat，选择 **官方网页**，打开对应厂商。

官网中的型号、历史和订阅由该官网管理。Workdesk 复用当前桌面网页视图的登录状态；本地对话记录保存 Workdesk 管理的入口信息。

### 4. 连接官方工作端

- **Codex**：在 **Work 账号** 中选择 Codex，点击 **前往官方登录**，完成 ChatGPT 官方授权。
- **DeepSeek**：保存 DeepSeek API Key 后，在 **设置 → 账号与模型** 查看工作连接。需要操作其官方桌面账号时，通过 **打开官方工作端** 使用本机已安装的 DeepSeek Harness 桌面应用。
- **Qwen**：保存用于当前工作路线的 Qwen Key；需要订阅账号操作时，从 **Work 账号** 选择 Qwen，按其官方登录入口完成。

连接完成后，选择界面中可用的型号、思考强度及服务选项。灰色项和“待接入”项的含义见[版本与支持范围](#chapter-14)。

## 三、认识工作台

顶部 **Chat / Work** 切换聊天与项目工作。左侧图标进入资料空间、工作与记录、插件与 Skills、额度和设置；把鼠标停在图标上可以查看名称。

Work 的侧栏按场景、项目和对话组织：点击项目名称看项目概览，点击项目下的对话接着工作。合作任务的内部回合从任务详情查看。

“工作与记录”提供四类总览：

|入口|用来查什么|
|---|---|
|**对话记录**|Chat、独立 Work、合作 Work，以及草稿|
|**任务**|任务状态、待验收事项和详情|
|**项目与工作区**|项目登记、场景及项目文件位置|
|**运行与计划**|当前运行、需要你处理的事项、预约和自动目标|

窗口较窄时，先收起左右侧栏，正文会获得更多空间；折叠的操作从 **更多** 中打开。

## 四、使用 Chat

### 1. 发起聊天

1. 切到 **Chat**，选择 **API 连接**。
2. 选择厂商和型号。需要时开启 **深度思考**；DeepSeek 路线还提供 **联网搜索**。
3. 输入问题，点击输入框右下角的发送箭头，或按 **Enter**。**Shift+Enter** 换行。
4. 回复期间可点击停止按钮。停止后，已经收到的正文仍保留在当前回合。

首条消息发送后，该会话固定厂商与型号。需要换模型时点击左侧 **新聊天**；默认型号设置用于新会话。

### 2. 添加附件和使用搜索

- 点击回形针，或把文件拖入聊天区；发送前核对名称，移除误选文件。
- 文本、PDF 文字、DOCX、EPUB 等附件先准备内容，再随消息提交。图片输入使用支持图片的 DeepSeek Flash 路线。
- 开启 **联网搜索** 后，发送时进行一次对应的官方搜索；需要时填写搜索词。
- 扫描 PDF 可能没有可提取文字；出现解析提示时，换成可复制文字的文件，或先准备文字内容。

### 3. 阅读与保存回答

回答可以显示标题、列表、表格、引用和代码块。代码块右上角的 **复制代码** 复制代码；消息操作中的复制入口复制原文。

上翻阅读时，Workdesk 保留阅读位置；点击回到最新位置的入口继续跟随回复。输入区始终保留在正文滚动区外。

查看上下文条了解当前会话占用。接近容量时先保存或导出重要内容，再新建聊天。

### 4. 处理失败或未知状态

失败或停止后，用 **复制原问题** 保留问题，需要调整时再编辑发送。

**注意：** 显示“发送状态未知”时，先核对原回合。再次发送会建立新的请求并按提供方规则计费；已收到的用量按原记录保留。

## 五、用独立 Work 处理项目

独立 Work 由一个所选官方工作端持续处理项目，适合写文档、修改代码、整理文件和执行工具任务。

### 1. 开始一项工作

1. 切到 **Work → 独立**。
2. 选择工作场景，点击项目选择框，使用已有项目或登记项目文件夹。
3. 选择工作端、型号、思考强度和权限。
4. 在输入框写清目标、输入材料、交付文件和完成要求。
5. 需要附件、Skill、MCP 或本地聊天材料时，点击输入区的 **＋**。
6. 点击输入框右下角的发送箭头，开始工作。

### 2. 审批、计划与继续工作

权限从 **请求批准** 起步。出现命令、工具或补充问题时，在当前回合中阅读并处理。

需要先看方案时，从输入区 **＋** 中选择 **计划模式**。独立 Work 使用工作端的计划或只读能力；方案准备好后，按当前状态继续执行。

接着做时，在原对话输入补充要求，点击右下角的发送箭头。当前可调整的型号、思考和权限在下一回合生效。

需要停止时，点击当前状态区的 **停止此回合**，等待结束状态。失败后可用 **重新编辑原问题** 将原问题放回输入区，修改后手动发送。

**注意：** **完全访问权限** 允许工作端在当前 Windows 账号权限范围内读写文件、运行命令和访问网络。项目文件夹指定工作位置，实际权限由工作端及本次授权决定。

### 3. 从任务详情接着处理

点击对话上方的 **任务详情**，按页签查看：

|页签|可以做什么|
|---|---|
|**概览**|查看任务背景、最近回合和验收情况|
|**运行与控制**|处理审批、补充输入、停止和状态核对|
|**成果与验收**|保存回复及指定文件，接受或退回成果版本|
|**任务设置**|查看或编辑任务名称、目标和完成要求|
|**额度消耗**|按任务、模型和回合查看用量与时间|

工作端回合结束后，继续按[成果验收](#chapter-7)保存和核对文件。

## 六、用合作 Work 分工

### 1. 选择合作方式

切到 **Work → 合作**，点击 **合作方式与分工**。旁边的问号可展开说明。

|方式|适合什么任务|怎样起步|
|---|---|---|
|**固定流程**|目标清楚、步骤可重复的工作|准备正式方案|
|**负责人带队**|需要负责人统筹、分配和汇总|先做第 0 轮需求讨论|
|**主持人—专家**|需要多个方向提供意见，再作取舍|先做第 0 轮需求讨论|

正式工作按 **P 规划 → D 执行 → C 检查 → A 改进与整理交付** 推进。一轮 PDCA 包含多个阶段；“工作回合”是某个工作端的一次派发或协调。

### 2. 核对合作安排再开始

1. 选择项目，填写目标和完成要求。
2. 点击输入框右下角的向上箭头，打开 **确认开始合作**；计划模式显示 **确认生成合作方案**。
3. 选择合作方式、PDCA 轮数及各角色使用的型号；负责人或主持人单独核对。
4. 查看准备、协调、阶段执行、最终核对和预留所需的回合合计。
5. 填写派发时限、回合上限及访问权限，勾选授权确认。固定流程点击 **确认并开始**；负责人带队或主持人—专家点击 **开始预讨论**；计划模式按页面点击 **生成方案**。

负责人带队和主持人—专家先进入 **第 0 轮 · 需求讨论**。补充范围与材料，阅读最终任务说明，再点击 **确认任务说明并开始 PDCA**；计划模式使用 **确认任务说明并生成方案**。

派发时限留空为 **24 小时**，当前最高 **168 小时**。到期会暂停新增派发，已经开始的回合继续按其状态处理。

### 3. 调整、暂停与续作

|入口|作用|
|---|---|
|**调整下一步**|保存给下一次派发的说明|
|**打断并暂停**|暂停后续派发，并请求停止当前准确回合|
|**续跑说明 → 从中断处继续**|核对中断位置，利用已保存前置成果接续|
|**调整派发设置**|展示轮数、累计上限和截止时间的变更，确认后应用|
|**继续这项合作 → 查看续作安排**|为已完成工作准备后续范围，再确认续作|

增加授权后，原累计用量继续保留；已有轮次之后的续作按页面所示顺序执行。

### 4. 查看过程与交付

合作详情分为 **操作与配置、执行纪要、执行轨迹、成果与验收、额度消耗** 五栏。读摘要用执行纪要，查阶段、工具和审批用执行轨迹。

最终交接出现在合作聊天中。点击交付文件可在右栏预览已保存版本，下载后使用；**在资源管理器中显示** 定位项目原件。

**注意：** 回合上限和派发时限限制的是工作授权。需求讨论、协调和正式执行使用模型服务时，均按相应服务规则计费。

## 七、项目、记录与成果验收

### 1. 管理项目位置

从 **项目与工作区** 登记已有文件夹，填写名称和场景。保存登记后，项目文件仍在你选择的位置。

项目原件已移动时，在项目卡中选择重新定位，查看 **目录核对预览** 后更新位置。Workdesk 更新登记路径；文件搬移由你在资源管理器中完成。

### 2. 查找对话和任务

点击左侧剪贴板图标进入 **工作与记录 → 对话记录**。页面标题为“全部对话记录”，可按 Chat、独立 Work、合作 Work 分类或搜索；草稿从草稿箱进入。无结果时点击 **清除筛选**。

从列表打开详情后，用返回入口回到原列表，保留筛选；**打开所属工作对话** 则进入对应聊天。

### 3. 保存并验收成果

1. 打开独立任务的 **成果与验收**，找到 **保存本回合成果**。
2. 需要保存文件时，填写项目中的相对路径，每行一个；留空则保存回复。
3. 打开保存的版本，核对回复、文件与完成要求。
4. 填写验收说明，点击 **接受此版本** 或 **退回此版本**。

保存成果会保留回复和所选文件的备份，项目原件留在原处。退回后需要继续修改时，在原工作中说明修改要求，再开始下一回合。

需要暂时收起记录时用归档；需要长期保留正文时先导出。项目仍有关联记录时，按页面原因处理后再移除登记。

**注意：** 删除确认只作用于列明的本地对象。正在执行或身份待核对的记录先处理对应回合，再删除；官网历史和项目原件分别在其原位置管理。

## 八、资料空间与右栏工具

### 1. 收录长期资料

进入 **资料空间**，使用 **全部资料、资料库、知识库、最近、回收站** 管理内容。

1. 点击 **新建**，选择 **新建页面**、**新建演示文稿**、**收录链接**、**收录文件** 或 **新建知识库**。
2. 填写标题、正文、备注、标签或归属。
3. 保存后，在列表中搜索和打开；页面可切换 Markdown 编辑与预览。

单个收录文件上限为 **8 MB**。支持预览的文件直接查看，其他格式下载后用相应应用打开。模型需要使用资料时，在目标工作中引用或附加。

### 2. 继续编辑与舍弃草稿

资料编辑框按当前资料库和条目暂存本窗口中的文字。点击 **关闭并保留暂存** 后，再打开同一条目可以继续；文件收录需要重新选择文件。

要清除这份暂存，点击 **舍弃暂存** 并在确认框中确认。遇到版本冲突时，先保留自己的文字，再核对另一处保存的版本。

### 3. 边聊边用右栏整理

在 Chat 或 Work 标题栏右上角点击面板图标，也可以按 **Ctrl+Shift+B**。展开后点击 **新建页面**、**新建演示文稿**、**侧边聊天** 或 **打开文件**。

|工具|操作|
|---|---|
|**快捷工作区**|搜索项目文件、本地聊天，或输入网页地址|
|**页面**|写标题和 Markdown 正文，预览、收录或导出 `.md`|
|**演示文稿**|编辑各页标题和正文，添加或删除页，导出 `.pptx`|
|**文件**|浏览项目、输入相对路径或选择本机文件进行预览|
|**侧边聊天**|通过已连接路线进行辅助聊天|

页面和演示文稿使用 **收录到资料空间** 保存长期资料；导出文件供其他软件继续编辑。

通过草稿下拉切换内容，修改标题即可重命名。**更多 → 删除草稿** 删除当前选中项。多窗口并行编辑发生冲突时，Workdesk 会保留独立的并行编辑版本，按名称和暂存时间选择。

工具页签的 **×** 关闭该工具，右上角的收起图标收起面板。**Ctrl+Shift+F** 在全宽与分栏间切换。

**注意：** 草稿保存失败时先复制文字，文件选择需重新进行。长期保留的页面和演示请收录或导出，再清理浏览器数据或更换电脑。

## 九、场景、Skills 与 MCP

场景用于组织工作与能力预设。Skills 提供可选工作方法，MCP 连接为工作端提供工具。

1. 打开 **设置 → 插件与 Skills**。
2. 在 **Skills** 点击 **导入 Skill**，查看内容后启用。
3. 在 **MCP 连接** 点击 **添加连接**，填写连接配置并检查状态。
4. 在 **场景与预设** 管理默认项。
5. 新建工作时，从输入区 **＋** 选择本次使用的能力。

**自然语言管理** 接受关于设置、场景和扩展的请求。选择解析成员、输入要求，查看识别结果和操作回执。

**注意：** 扩展按其配置读取文件、运行程序和访问服务。首次启用前查看用途与权限；具体可用能力由所选官方工作端提供。

## 十、查看用量与账户额度

点击左下方额度图标打开 **余额与用量**。详细记录从 **设置 → 用量与预算** 查看。

|栏目|读什么|
|---|---|
|**账户额度**|提供方返回的订阅窗口、Credits、余额和免费 Token|
|**Token 活动**|本机收到的输入、缓存与输出 Token 记录|
|**调用消耗**|调用次数、原生回执、明细与估算费用|
|**工作用量**|按整项工作、模型、步骤和回合汇总的消耗|

“近 7 天已记录”统计本机收到的回执。缺少字段会显示缺项；查询失败时，先看仍在显示的读数时间。

Qwen 的主金额是 **可用额度**，**现金余额** 单独显示；百炼免费 Token 与账单余额分别授权和查询。按所需项目完成官方工具授权，再点击查询。

DeepSeek Token 费用按回执和界面计价依据估算。实际扣款、搜索费用及其他设备上的消耗，以提供方账单为准。

## 十一、计划、预约与自动目标

进入 **运行与计划 → 计划**，选择任务类型：

|类型|怎样使用|
|---|---|
|**固定流程预约**|为已经准备并授权的固定合作任务安排一次启动|
|**合作重复计划**|按天或周执行已就绪的固定合作方案，每周期保存成果|
|**自动目标**|保存目标和完成标准，再点击 **启动 / 继续**，由一个工作端分回合推进|
|**定时计划**|为已完成的独立工作安排后续指令，点击 **保存并启用计划**|

保存前检查项目、工作端、时区、首次时间、最多次数或回合，以及实际发送的内容。自动目标首次使用可以设置有限回合。

**计划只在 Workdesk 后台服务运行且电脑处于工作状态时派发。** 关闭桌面窗口后，后台服务仍可继续运行。休眠或服务停止期间暂停派发；服务重启后先核对再手动继续，错过的窗口不自动补发。断网时按页面记录的失败或未知状态处理。

点击 **暂停后续派发** 阻止下一次启动；已有回合从运行入口停止并核对。模型报告完成后自动派发停止，由你验收成果。

**注意：** 启用定时计划即授权在指定时间发送所填内容。计划继续执行时，模型调用按提供方规则计费。

## 十二、数据、密钥与备份

### 1. 数据分别在哪里

|位置|保存内容|
|---|---|
|Workdesk 程序文件夹|启动入口、界面和随附运行环境|
|`.workdesk-dev`|用户配置、连接资料和本地运行信息|
|其中的 `libraries\main`|默认资料库：对话、任务、资料、用量回执与已保存成果|
|你选择的项目文件夹|模型实际处理的项目原件|
|桌面网页视图或浏览器的本地存储|网页登录状态、输入草稿、右栏草稿与界面状态|

从源码启动时，`.workdesk-dev` 位于项目根目录。在 **设置 → 本地存储与恢复 → 查看保存位置** 核对实际资料库，也可从该页更换位置。

### 2. Key 与登录信息

通过连接页保存的 API Key 位于用户目录的 `config\provider-keysets\<编号>\.env`，由 Windows 当前用户的 DPAPI 加密保护。当前选择记在 `config\credential-references.json`；更新 Key 时，Workdesk 保存新版本并切换引用。高级设置中选择的外部 Key 文件沿用该文件原来的保存方式。

Codex 使用专用认证目录；其他官方工作端、额度工具和官网视图的登录资料分别保存在用户目录中的对应位置。账号退出、切换和重新授权，通过账号连接或相应官方页面完成。

### 3. 哪些内容会发送到外部

|操作|发送什么、由谁处理|
|---|---|
|API Chat|发送当前请求所需的会话消息与已提交附件内容，由所选模型提供方处理|
|联网搜索|把本次搜索请求交给对应的官方搜索服务|
|Work|由所选官方工作端发送任务消息，以及执行中读取并纳入请求的文件或工具结果|
|官网 Chat|在官网填写和上传的内容直接由该官网处理|
|MCP、插件与外部工具|按工具配置向对应服务发送请求和所需数据|
|额度查询|向相应官方服务查询账号的额度或账单信息|

收录资料用于本地整理。需要模型阅读时，在目标对话或工作中引用、附加内容；工作端也会按授权读取项目文件。整理敏感资料时，先选择合适的模型服务和工具权限。

### 4. 创建与恢复备份

1. 结束或核对在途工作、API 聊天及额度查询。
2. 打开 **设置 → 本地存储与恢复**，点击 **创建备份**。
3. 从 **管理备份** 查看并导出需要保留的备份。
4. 恢复时用 **选择备份** 登记文件，再到 **管理恢复** 验证、暂存并明确切换资料库。
5. 切换后核对项目路径、连接和运行状态，再继续工作。

|需要保留什么|怎样保存|
|---|---|
|Workdesk 管理的资料与记录|使用资料库备份|
|项目原文件|另行备份你选择的项目文件夹|
|右栏页面与演示草稿|先收录，或导出 `.md` / `.pptx`|
|账号连接|在新电脑重新连接自己的账号|
|官网历史|使用官网提供的历史或导出功能|

### 5. 清理个人资料

保留资料时，保留资料目录。需要彻底清理时，先导出所需内容，停止后台服务，再删除实际使用的用户资料目录。自行选择的项目原件和浏览器站点数据分别清理。

**注意：** 删除用户资料目录会移除该目录内的账号连接和本地记录。先创建备份，并核对当前实际保存位置。

## 十三、常见问题与故障反馈

### 1. 按页面提示处理

|看到的情况|怎样处理|
|---|---|
|桌面窗口打不开或网页视图无法建立|检查 WebView2 Runtime，再按开发说明启动工作台。如有启动失败提示，记录弹窗内容|
|提示程序文件缺失|按开发说明重新构建前端|
|连接失败、Key 无效|在账号连接入口核对提供方和 Key，保存后检查连接|
|型号灰色或不可用|刷新型号目录，检查当前账号与工作连接，再选择可用项|
|提示控制服务来自旧工程或旧版本|结束在途工作，在设置中按页面提示重载空闲控制服务，再重试|
|等待审批或等待补充|进入当前准确回合，阅读请求并处理|
|正在停止、停止待核对|等待并刷新状态，从原回合核对后续操作|
|发送状态未知、重启后待核对|查看原回合和工作端状态，再决定停止或续接|
|交付文件缺失|查看缺项，在原任务补充说明或从中断处继续|
|保存冲突或收录失败|先保留自己的文字，核对已保存版本，再另存或重试|
|备份或资料切换被拒绝|先处理在途查询、工作和未知状态，再操作|
|偏好读取损坏|按设置页恢复可用备份或默认设置，再检查目录和审批选项|

### 2. 找到需要处理的运行

进入 **运行与计划 → 运行**，先看“需要处理”“进行中”“人工接管”。日常恢复入口在 **设置 → 运行与恢复**；进一步查看历史、回执或接管操作时，进入 **恢复工具与诊断**。

### 3. 反馈问题

把问题反馈给向你提供 Workdesk 的维护者，附上：

1. Workdesk 版本与构建标识，见下一节；也可以到 **设置 → 帮助与诊断 → 服务与诊断** 查看 **实现版本**。
2. 出错页面、发生时间和重复出现的操作步骤。
3. 页面错误原文、任务或回合名称，以及去掉私人内容的截图。
4. 启动失败时，附上终端或弹窗中的启动错误信息。若提示已保存启动诊断，可在资源管理器中打开 `.workdesk-dev\runtime\ui`，查看 `startup-error.txt`。

提供诊断材料时，先移除 Key、登录文件和私人项目正文；保留能说明问题的错误与操作信息即可。

## 十四、版本、支持范围与快捷键

### 1. 版本信息

本指南面向 Workdesk 的 Windows 11 x64 源码版本。开发入口、资料位置和各工作端的依赖见[开发说明](DEVELOPMENT.md)。

### 2. 重要边界

- **模型与工作端**：当前按 Codex、DeepSeek、Qwen 的实际连接和可选型号使用；“待接入”项本版本不提供执行。
- **原生能力**：各官方工作端提供自己的工具与权限。新建对话保存会话身份，项目目录保存文件，执行权限决定实际访问范围。
- **聊天与工作**：API Chat 用于对话和已提交附件；本机文件操作与命令任务使用 Work。
- **长对话**：API Chat 首条后固定厂商和型号；上下文接近上限时保存并新建会话。
- **恢复**：备份恢复记录与资料；模型进程、官网历史和浏览器草稿按各自机制接续。
- **演示文稿**：右栏用于标题、正文和多页整理，导出可编辑 `.pptx`；复杂模板、动画与精细排版在演示软件中完成。
- **更新**：本版本手动更新；自更新、自维护、自定义界面和用户后开发不在本版本提供。

### 3. 常用快捷键

|快捷键|用途|
|---|---|
|**Enter**|在支持该方式的输入区发送|
|**Shift+Enter**|输入区换行|
|**Ctrl+K**|设置中聚焦设置搜索；其他工作台区域进入记录搜索|
|**Ctrl+Shift+B**|打开或收起右栏|
|**Ctrl+Shift+F**|右栏已打开时切换全宽视图|
|**Esc**|关闭当前菜单或弹窗；右栏退出全宽或收起|
|**Ctrl+W**|关闭桌面窗口，按关闭确认设置处理|

完整清单在 **设置 → 键盘快捷键** 查看。焦点位于官方网页、菜单或弹窗时，由当前界面优先处理按键。
